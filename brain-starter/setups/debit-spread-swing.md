# 借方价差短线

**论点**：有明确催化或技术结构时，用借方垂直价差表达方向，降低 IV 和 theta 暴露。

**入场条件**
- 有具体论点（催化 / 突破 / 板块轮动），写进交易页。
- 买 50–60Δ，卖 25–30Δ，到期 7–21 天。
- IV/RV > 1.2 时优先用价差而非单腿。

**失效 / 止损**
- 论点失效（例如跌回突破位）→ 离场，不看盈亏。
- 亏损达价差成本的 50% → 离场。

**目标**：价差最大价值的 60–70%。
