# 周度校准报告（skill）

每周五盘后。数据来源：takes_scorecard、takes_calibration、本周 trades/ 页面。

输出：
1. **本周数字**：交易笔数、胜率、总盈亏、平均盈亏比。
2. **校准**：Brier 分数；按置信度分桶（0.5–0.6 / 0.6–0.75 / 0.75+）的实际命中率 vs 声称置信度。指出"过度自信"或"过度保守"的桶。
3. **按 setup 拆分**：每个 setup 的笔数、胜率、期望值。期望值为负且 ≥ 5 笔的 setup 建议暂停。
4. **纪律违规**：本周违反 people/me 纪律的次数与类型。
5. **下周一件事**：只给一条最重要的调整。
