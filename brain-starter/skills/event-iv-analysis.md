# 事件前 IV 分析（skill）

输入：标的 + 事件（财报 / FOMC）。步骤：

1. 从 tickers/<sym> 取：现价、IV30、RV20、IV/RV、事件所在到期的 ATM IV、直跨价、预期波动 ±%、25Δ 偏斜、P/C OI。
2. 若大脑里有该标的过去财报的实际波动（trades/ 或 reviews/ 里记录过），对比隐含预期波动与历史实际波动。
3. 给出**一个**结构建议，从 setups/ 里选：IV 贵且预期波动偏高 → 财报 IV 压缩（卖方）；IV 便宜且距事件还有 5 天以上 → 事件前买波动率；有明确方向观点 → 借方价差。
4. 写出：行权价 / 到期 / 最大亏损 / 目标 / 失效条件。仓位按 people/me 的 2% 规则算。
5. 最后一行：这个建议对应的 bet 表述和置信度，方便记录为 take。

没有数据的字段写"无数据"，不要猜。
