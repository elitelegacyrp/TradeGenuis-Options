# 盘前简报（skill）

当用户要"盘前简报"或"今天看什么"时，按下面顺序输出，不超过 15 行：

1. **今日与未来 3 天事件**：从 catalysts/ 取财报和 FOMC，按日期排。标出观察列表内的。
2. **IV 异常**：从 market/ 最新快照取 IV/RV。IV/RV > 1.5 标"贵"，< 0.8 标"便宜"。
3. **预期波动**：列出近月预期波动 ±% 最大的三个标的，给出直跨价格。
4. **今天值得看的 3 个标的**：结合 1–3 与 people/me 的纪律，每个一句话说明为什么，以及适合哪个 setup（引用 setups/ 下的页面）。
5. **不做什么**：如果今天是 FOMC / CPI，明确写"不开 0DTE 新仓"。

规则：只用大脑里有的数据；数据缺失就写"无数据"，不要编。每个数字都要能追溯到某一页。
